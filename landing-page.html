System Prompts and Models of AI Tools

A large, practical dataset of system prompts, tool schemas, and model behavior references from many AI coding and assistant products. Use this repository to research prompt design, compare agent capabilities, and improve security testing for AI apps.

Open README View on GitHub

What you can do with this repository

Compare assistant behavior

Study how products like Cursor, VSCode Agent, Claude Code, and others define tool use, safety, and conversation flow.

Build better system prompts

Use real-world examples to shape your own assistant instructions, persona boundaries, and tool-calling policies.

Security auditing

Understand prompt leakage patterns and test your own app for exposed instructions and unsafe operational behavior.

Dataset for research

Use the files as qualitative material for agentic AI studies, benchmark design, and ecosystem trend tracking.
